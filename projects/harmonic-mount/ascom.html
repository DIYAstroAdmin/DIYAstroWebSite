ASCOM driver

A Windows ASCOM telescope driver that lets the mount work with standard astronomy and imaging software.

Overview

ASCOM is the standard way for Windows astronomy software to control equipment. The DIY Astro driver implements the ASCOM ITelescopeV4 interface. It runs as a local server, so several programs (for example N.I.N.A. and PHD2) can share the mount at the same time.

Requirements

  • Windows 10 or 11 (64-bit)
  • ASCOM Platform 7 or later
  • .NET Framework 4.8 (included with current Windows)
  • A DIY Astro HD mount running firmware v1.0 or later, connected by USB or Wi-Fi

Installation

  1. Install the ASCOM Platform if it isn’t already installed.
  2. Download and run DIYAstro-HD-ASCOM-Setup.exe (link below).
  3. In your imaging software, open the telescope chooser and select DIY Astro HD Mount.
  4. Click Properties… to open the setup dialog.

Setup dialog

SettingDescription
ConnectionUSB (COM port) or Wi-Fi (IP address / host name and port)
SiteLatitude, longitude and elevation. These can be synced from the imaging software.
Mount profileRead from the controller (Mini / Midi / Maxi). Shown for confirmation.
Guide ratesRA and Dec guide rates as a fraction of sidereal (default 0.5×)
LimitsMeridian flip offset and horizon limit
Trace loggingWrites a detailed ASCOM log for troubleshooting

Supported capabilities

  • Slew and sync (synchronous and asynchronous)
  • Tracking on/off with selectable rates
  • Pulse guiding
  • Park / unpark / find home
  • Side-of-pier reporting and meridian flips
  • MoveAxis (manual jogging)
  • Alt/Az and equatorial coordinates
  • Alpaca support (planned)

Tested with

N.I.N.A., PHD2, SharpCap, Cartes du Ciel, Stellarium (via ASCOM) and the ASCOM Conform Universal validation tool.

Troubleshooting

Mount not found on USB? Check that the COM port shown in Windows Device Manager matches the one in the setup dialog. Close any serial terminal that may be holding the port open.

Guiding pulses have no effect? Make sure PHD2 is set to use the ASCOM mount for guiding (“On-camera” guiding uses the ST-4 port instead), and that tracking is switched on.

Controller firmware

One firmware for all three mount variants. It runs on an ESP32-S3 controller board with Trinamic stepper drivers.

Project

  • Overview

Features

  • Sidereal, lunar, solar and King tracking rates
  • GoTo with smooth acceleration and deceleration
  • Pulse guiding (via ASCOM) and an ST-4 guide port
  • Park, unpark and home positions stored in flash
  • Optional hall-effect home sensors
  • Meridian and horizon limits
  • Optional periodic error correction (PEC)
  • USB serial and Wi-Fi (TCP) connections
  • Built-in web page for configuration and status
  • Over-the-air (OTA) firmware updates

Hardware platform

MicrocontrollerESP32-S3 (dual-core, Wi-Fi, native USB)
Stepper driversTMC2209 (UART) for Mini/Midi, TMC5160 (SPI) for Maxi
Step generationHardware timer-driven, with RA and Dec on independent timers
InputsST-4 guide port, 2× home sensors, optional hand controller
Power12–24 V DC input, reverse-polarity protected

Configuration

Each mount variant is selected with a compile-time profile. Most settings can also be changed at runtime from the built-in web page.

// config/mount_midi.h
#define MOUNT_NAME          "DIY Astro HD Midi"
#define RA_GEAR_RATIO       (100.0 * 3.0)   // harmonic drive x belt
#define DEC_GEAR_RATIO      (100.0 * 3.0)
#define MOTOR_STEPS_PER_REV 400             // 0.9 degree motors
#define MICROSTEPS          256
#define RA_RUN_CURRENT_MA   900
#define DEC_RUN_CURRENT_MA  900
#define MAX_SLEW_DEG_PER_S  3.0
#define ACCEL_DEG_PER_S2    1.5

Building and flashing

The firmware is built with PlatformIO, either from VS Code or the command line.

# clone the source (link to follow)
cd diyastro-hd-firmware

# build for the Midi and upload over USB
pio run -e midi -t upload

# watch the serial log
pio device monitor -b 115200

After the first USB flash, you can install later updates over Wi-Fi from the web page.

Command protocol

The controller understands a subset of the widely used LX200 command set, so many planetarium programs can talk to it directly. It also has extended :X...# commands for configuration and diagnostics. The ASCOM driver uses the extended commands for its full feature set.

CommandDescription
:GR# / :GD#Get right ascension / declination
:Sr..# / :Sd..#Set target RA / Dec
:MS#Slew to target
:Q#Abort slew
:Mgn####Pulse guide (n/s/e/w, milliseconds)
:hP#Park
:XGS#Get extended status (DIY Astro extension)

About DIY Astro

Astrophotography projects designed, built and tested at home, and shared so that others can build them too.

The story

DIY Astro started from a simple question: how much of my astrophotography kit could I design and build myself? The answer turned out to be “quite a lot”, and building the kit has been as rewarding as using it.

This site is where I publish my projects: mechanical designs, electronics, firmware and software, with honest notes on what worked, what didn’t and what I would do differently. The first project is a harmonic drive telescope mount, which has its own controller firmware and ASCOM driver.

Philosophy

  • Buildable: designed for home workshops, using parts you can actually buy.
  • Open: drawings, source code and notes are published in full.
  • Tested: every project is used under the night sky before it’s published.
  • Compatible: works with standard tools such as ASCOM, N.I.N.A. and PHD2.

Licence & disclaimer

Designs and documentation are shared for personal, non-commercial use. Firmware and software licences are given with each download. Building and using these projects is at your own risk. Please take care with mains power, machine tools and heavy, moving equipment.
